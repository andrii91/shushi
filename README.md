# ДеПожрать — меню ресторану

Односторінковий сайт-меню для ресторану з мультимовністю (PL / EN / UA) та простою адмін-панеллю на PHP для редагування контенту без правок коду.

## Що це за проєкт

- **Фронтенд** — Vue 3 + TypeScript + Vite. Показує меню (категорії, страви, ціни, фото), контакти, години роботи, соцмережі. Вибрана мова та обрані позиції («закладки») зберігаються в `localStorage`.
- **Бекенд** — легка PHP-адмінка (`/admin/`) без бази даних. Дані лежать у JSON-файлах, картинки — у звичайних теках. Адмінка читає/пише ці файли, фронтенд читає їх у рантаймі через `fetch`.
- Увесь редагований контент керується через адмінку: меню, **назва закладу, телефон, валюта, логотип, фон шапки, адреса, посилання на карту, години роботи, соцмережі** (Instagram, Facebook, TikTok, YouTube, Telegram, WhatsApp, Viber, X).

## Структура

```
src/                 — вихідний код Vue-застосунку (імпорти через аліас @ → src/)
  App.vue            — головний екран (шапка, меню, футер)
  components/        — компоненти (картки, модалка, перемикач мов)
    icons/           — SVG-іконки (закладка, кошик, стрілка, прапори)
  composables/       — спільна логіка (валюта, обране, локаль)
  utils/             — хелпери (трансформація меню, i18n)
  locales/           — переклади інтерфейсу та меню (pl/en/ua)
  types/             — типи (MenuItem, SiteSettings)
public/              — статика, що копіюється в dist без обробки (КОД, перезаписується кожен білд)
  admin/             — PHP-адмінка
    index.php        — UI адмінки (меню + налаштування сайту)
    api.php          — збереження меню (data/menu.json)
    settings.php     — збереження налаштувань (data/settings.json)
    upload.php       — завантаження зображень
    config.php       — пароль адмінки та шляхи
  favicon/           — іконки сайту
seed/                — ПОЧАТКОВІ дані (шаблон). Засіваються в dist лише якщо там їх ще нема
  data/              — menu.json, settings.json
  images/            — картинки (menu/ — страви, site/ — лого та фон)
dist/                — зібраний проєкт + ЖИВІ дані (їх пише адмінка), його деплоять на сервер
```

> **Розділення коду й даних.** `public/` — це код (PHP, favicon), який білд щоразу перезаписує в `dist/`. `seed/` — початковий шаблон даних: білд копіює його в `dist/` **лише для файлів, яких там ще нема**. Тому правки, зроблені через адмінку (вона пише в `dist/data` та `dist/images`), **переживають ребілд** і не затираються. Свіжа установка отримує дані з `seed/`.

## Запуск

Потрібні **Node.js** (для збірки фронтенду) і **PHP** (для адмінки).

### Варіант 1 — повний сайт із адмінкою (як на проді)

PHP-сервер віддає зібраний `dist/`: і Vue-сайт, і PHP-адмінку, і дані.

```bash
npm install
npm run build      # зібрати фронтенд у dist/
npm run serve      # підняти PHP-сервер на http://localhost:8000
```

Або однією командою (збірка + сервер):

```bash
npm run start
```

Відкрити:
- сайт — http://localhost:8000/
- адмінка — http://localhost:8000/admin/ (пароль за замовчуванням: `demo1234`, змінюється в `public/admin/config.php`)

> Після змін у Vue-коді потрібно перезібрати (`npm run build`) — сервер віддає файли з диска, перезапускати його не обовʼязково.

### Варіант 2 — фронтенд із гарячим перезавантаженням (без адмінки)

Зручно для активної розробки інтерфейсу. PHP-адмінка тут не працює (Vite не виконує PHP), але сайт читатиме `data/*.json` напряму.

```bash
npm run dev        # http://localhost:5173
```

### Якщо PHP не встановлено

**macOS** (через [Homebrew](https://brew.sh)):

```bash
brew install php
```

**Linux** (Debian / Ubuntu):

```bash
sudo apt update && sudo apt install php-cli
```

Fedora / RHEL: `sudo dnf install php-cli` · Arch: `sudo pacman -S php`

**Windows:**

- Найпростіше — [XAMPP](https://www.apachefriends.org/) або [Laragon](https://laragon.org/): встановлюють PHP разом із сервером.
- Або вручну: завантажте PHP із [windows.php.net/download](https://windows.php.net/download/), розпакуйте (напр. у `C:\php`) і додайте цю теку до `PATH`.
- Команди запуску ті самі (`npm run build`, `npm run serve`). У PowerShell / CMD замість `$PWD` використовуйте повний шлях, якщо знадобиться.

Перевірити, що PHP доступний (будь-яка ОС):

```bash
php -v
```

> Node.js (для збірки фронтенду) ставиться з [nodejs.org](https://nodejs.org/) на всіх системах однаково.

## Дані та адмінка

- **Меню** редагується у вкладці категорій: додавання/видалення категорій і страв, ціни, описи трьома мовами, завантаження фото, перетягування для зміни порядку. Зберігається в `data/menu.json`.
- **Налаштування сайту** — блок «⚙️ Налаштування сайту»: назва, телефон, валюта, лого, фон шапки, адреса, карта, години роботи, соцмережі. Зберігається в `data/settings.json`.
- Якщо `data/settings.json` недоступний, фронтенд показує вбудовані значення-фолбеки.
- При збереженні адмінка **сама прибирає невикористані картинки**: стару лого/фон при заміні, фото видалених страв.

## Деплой

Завантажити вміст `dist/` у корінь сайту на хостингу з підтримкою PHP. Перед публікацією **обовʼязково змініть пароль** у `public/admin/config.php` (`ADMIN_PASSWORD`) і перезберіть проєкт.

> **Дані переживають ребілд.** Білд не витирає `dist/` (`emptyOutDir: false`) і копіює `seed/` лише для відсутніх файлів. Тому правки контенту через адмінку (`dist/data`, `dist/images`) зберігаються при повторних збірках. На свіжому сервері перший білд засіє дані з `seed/`. Щоб скинути контент до шаблону — видали відповідні файли в `dist/` і перезбери (або відредагуй `seed/`).
